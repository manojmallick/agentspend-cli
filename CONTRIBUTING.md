# Contributing to agentops

Thanks for contributing to agentops.

## Branch workflow

agentops uses a single `main` branch. Open pull requests against:

```
main
```

## Recommended branch names

```
feat/spend-report-csv
fix/sync-missing-profile-error
docs/readme-examples
test/spend-budget-edge-cases
```

## Pull request checklist

Before opening a PR, please check:

* [ ] The change has a clear purpose
* [ ] Tests were added or updated when needed (`src/test/`)
* [ ] `pnpm test` and `pnpm typecheck` pass
* [ ] Documentation was updated for user-facing changes (README, this file)
* [ ] A changeset was added for any user-facing change: `pnpm changeset`
* [ ] No new dependency was added unless discussed first

## Local commands

```bash
pnpm install
pnpm dev -- spend track --provider openai --cost 0.42   # run from source
pnpm typecheck
pnpm test
pnpm build && node dist/cli.js --help                    # run the compiled CLI
```

## Contributor credit

Contributors are credited in:

* the original PR
* `CHANGELOG.md` (generated by Changesets on release)
* GitHub release notes

## Commit format

```
type(scope): short description (under 72 chars)

Types: feat / fix / docs / test / chore / refactor / perf
Scopes: spend / sync / cli / ci / release / docs / test
```

## Releasing

1. `pnpm changeset` — describe the change and its version bump (patch/minor/major)
2. Commit the generated `.changeset/*.md` file along with your change
3. Merging to `main` triggers the `deploy-npm-publish` GitHub Actions workflow, which opens a "Version Packages" PR
4. Merging that PR publishes the new version to npm (requires the `NPM_TOKEN` secret)
