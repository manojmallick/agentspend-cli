# agentops

Generated by `create-universal-app` (cli-tool). Commander for argument parsing, Changesets
for versioning/publishing. Deploy (npm publish via GitHub Actions), CI, and sigmap are
pre-wired — build the app in `src/logic/`.

## Develop

```bash
pnpm install
pnpm dev -- hello world
```

## Release

```bash
pnpm changeset        # describe your change
git commit -am "..."  # commit the changeset file
```

Merging to `main` triggers the `deploy-npm-publish` GitHub Actions workflow (Changesets
opens a "Version Packages" PR; merging that publishes). Requires an `NPM_TOKEN` secret.
